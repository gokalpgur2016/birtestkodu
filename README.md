# birtestkodu

Bu proje test amaçlı oluşturulmuştur. Vercel üzerinde yayınlanacak basit bir HTML sayfası içerir.

## 🔍 Amaç
# Gökalp'in Kanalı

## 📌 Proje Açıklaması
Bu proje, **Gökalp'in YouTube kanalını tanıtmak** için hazırlanmış basit bir web sayfasıdır.  
HTML ve CSS kullanılarak tasarlanmıştır. Arka planda Minecraft temalı görseller ve modern tasarım öğeleri kullanılmıştır.  

---

## 🎨 Özellikler
- Başlık ve kanal tanıtımı  
- YouTube abonelik butonu  
- Son video iframe ile gömülü  
- Hakkımda bölümü  
- Şık tasarım ve responsive yapı  

---

## 🚀 Kullanım
1. Bu dosyayı bilgisayarınıza indirin.  
2. `index.html` dosyasını bir tarayıcıda açın.  
3. YouTube videosu ve kanal bağlantısı aktif olarak çalışacaktır.  

---

## 📂 Dosya Yapısı
- `index.html` → Ana HTML dosyası  
- CSS kodları HTML içinde `<style>` etiketiyle yazılmıştır.
